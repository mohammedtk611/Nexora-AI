NIST SP 800-61 REV 2 INCIDENT HANDLING GUIDE REFERENCE
================================================================================
DOCUMENT CLASS: COMPLIANCE GROUNDING STANDARD
PURPOSE: Standardized operational response steps for Security Advisories & Executive Briefings.

PHASE 1: PREPARATION
- Establish incident response teams, automated logging, and baseline security controls.
- Maintain immutable audit trail logs for all administrative operations.

PHASE 2: DETECTION & ANALYSIS
- Categorize incident severity based on CVSS scoring:
  * CRITICAL: CVSS 9.0 - 10.0
  * HIGH: CVSS 7.0 - 8.9 (e.g., INC-2026-8894 CVSS 8.4)
  * MEDIUM: CVSS 4.0 - 6.9
  * LOW: CVSS 0.1 - 3.9
- Collect IoCs including source IP addresses, payload hashes, and HTTP headers.

PHASE 3: CONTAINMENT, ERADICATION & RECOVERY
- Immediate Containment: Isolate compromised hosts and block malicious source IPs at firewall.
- Eradication: Apply software security patches and revoke active authentication tokens.
- Recovery: Verify host operational integrity before restoring production traffic.

PHASE 4: POST-INCIDENT ACTIVITY
- Conduct lessons-learned review within 72 hours of incident resolution.
- Publish Security Advisory and Executive Brief deliverables.
